# Просмотр 3D-модели на главной

На широком экране окно модели находится слева, а существующие три блока сайта —
справа. На экранах уже 1200 px окно модели располагается над остальным содержимым.
Посетитель может вращать модель, приближать её, перемещать камеру, возвращать исходный
ракурс и открывать полноэкранный просмотр.

## Замена модели

Редактируйте `html/model-viewer.json`. Настройки общие для всех посетителей:

| Поле | Назначение |
| --- | --- |
| `src` | Адрес файла GLB/glTF, например `/models/makima.glb`, или прямая HTTPS-ссылка. |
| `title`, `alt` | Название в окне и описание для средств доступности. |
| `poster` | Адрес изображения до загрузки модели; `null` отключает изображение. |
| `cameraOrbit` | Начальный ракурс: горизонтальный угол, вертикальный угол, расстояние. |
| `cameraTarget` | Точка, вокруг которой вращается камера; `auto auto auto` выбирает центр. |
| `fieldOfView` | Угол обзора камеры. |
| `autoRotate` | Автоповорот; учитывает системную настройку уменьшения движения. |
| `credit` | `null` или объект с `label` и `url` для подписи автора и ссылки на источник. |

Публичные модели размещайте в `html/models/`. Ссылки считаются относительно
`/model-viewer.json`. Для GLTF с отдельными ресурсами сохраняйте структуру папок с
текстурами и BIN-файлами. Внешний сервер должен разрешать CORS-загрузку с домена сайта.
Ссылка на страницу Sketchfab не заменяет адрес GLB/glTF: для такого персонажа нужен
доступный файл модели.

В production Caddy читает статические файлы с хоста. После замены модели и JSON
перезапуск сервисов не требуется; уже открытым страницам нужно обновление. JSON
загружается без кеша. Изображения кешируются отдельно, поэтому при замене постера
используйте новое имя файла.

## Подготовка исходной модели

Исходные файлы Makima находятся в `../../models/`. Публичная копия
`html/models/makima.glb` использует Meshopt-сжатие. Проверка подготовки заново
декодирует результат и сравнивает геометрию и текстуры с исходником побайтово.
Уменьшение числа полигонов и пересжатие текстур не выполняются. Результат и контрольные
суммы записываются в соседний JSON-файл.

Из `services/website` выполните:

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run prepare:model -- ../../models/makima-chainsaw-man-t-pose-3d-model/source/ip-chainsaw-man__makima__concept__tpose.glb html/models/makima.glb
```

Обычный несжатый GLB также можно разместить в публичном каталоге и указать в настройках.
Исходная модель содержит много геометрии; фактическая плавность зависит от устройства
посетителя. Сжатие сокращает передачу данных, сохраняя сложность сцены.

## Зависимости и проверка

`model-viewer` и декодеры поставляются локально в `html/vendor/model-viewer/`.
Версии и целостность npm-пакетов фиксируются в `package-lock.json`. Для обновления
поставляемых файлов после изменения зависимостей выполните:

```powershell
npm.cmd ci --ignore-scripts
npm.cmd audit --audit-level=moderate
npm.cmd run vendor
```

Политика безопасности просмотрщика настроена отдельно для `/viewer/`: разрешены
HTTPS-модели, декодеры WebAssembly и необходимые библиотеке стили. Скрипты загружаются
с собственного домена. Главная страница сохраняет свою отдельную политику.

Из корня проекта запускаются общие и браузерные проверки:

```powershell
uv run --locked python scripts/check.py --audit
uv run --locked --group browser python scripts/check_website_browser.py --url https://dedvnutri.space
```

Браузерная проверка использует настоящий Chrome/WebGL, проверяет управление камерой,
семь размеров экрана и CSP. Ключ `--fixture PATH.glb` позволяет проверить модель с
изолированными ответами внешних API, включая отказ загрузки и повторную попытку.

Документация компонента: https://modelviewer.dev/docs/index.html.
